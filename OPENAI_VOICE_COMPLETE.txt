│ 🎬 HOW IT WORKS                                                              │
├──────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  User Journey:                                                              │
│                                                                              │
│  1. User opens reasoning panel                                              │
│  2. Clicks "🎤 Record" button                                               │
│  3. Browser asks for mic permission → User allows                           │
│  4. User speaks: "What alternatives did you consider?"                      │
│  5. Clicks "⏹ Recording..." to stop                                         │
│  6. Status changes to "Transcribing..."                                     │
│  7. Audio sent to OpenAI Whisper API                                        │
│  8. Transcript appears: "What alternatives did you consider?"               │
│  9. Question sent to Ava (/api/explain)                                     │
│  10. Ava generates response text                                            │
│  11. Response sent to OpenAI TTS API                                        │
│  12. Natural-sounding audio plays back                                      │
│  13. User hears professional voice response                                 │
│                                                                              │
│  Total latency: ~2-4 seconds (network + processing)                         │
│                                                                              │
